# EdwardsIndexAI

This is the Xcode 10.3-compatible UIKit port of the SwiftUI iOS app concept based on the UML model:

- Theme
- BookCoordinate
- IndexMarker
- Annotation

It is intentionally kept simple and compatible with older tooling while still preserving the conceptual structure and local SQLite persistence approach.

## Notes

- This version targets UIKit and Xcode 10.3 compatibility.
- It is not a full production app yet.
- It is designed as a compatibility port and a foundation for future generator-based iOS code generation.
